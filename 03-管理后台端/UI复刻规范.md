# 管理后台端 UI 复刻规范

## 1. 视觉基准

基准概念图：

```text
D:\Project\SilverLink Care\ui_overview_images\new_03_admin_security_overview.png
D:\Project\SilverLink Care\ui_overview_images\new_04_full_flow_overview.png
```

后台端以 `new_03_admin_security_overview.png` 为主，`new_04_full_flow_overview.png` 作为全链路演示参考。

## 2. 整体风格

- 风格：医疗志愿服务运营后台，克制、清晰、可审计。
- 页面基调：深色侧边栏 + 白色内容面板 + 中性色背景。
- 信息密度：比移动端更高，但表格和面板必须清楚分组。
- 不能做成营销页或大屏可视化炫酷风。

## 3. 颜色规范

| 用途 | 颜色建议 | 用法 |
| --- | --- | --- |
| 页面背景 | `#EEF2F5` | 后台整体背景 |
| 侧边栏 | `#132C3A` | 左侧导航 |
| 菜单选中 | `#1C7488` | 当前菜单 |
| 主色 | `#115F72` | 登录按钮、主要操作 |
| 成功色 | `#0A8067` | 启用、通过、安全 |
| 风险色 | `#C2410C` | 异常访问、失败 |
| 文本主色 | `#17212B` | 标题、表格主字段 |
| 文本次色 | `#687989` | 说明、辅助字段 |
| 边框色 | `#D9E2E8` | 面板、表格边框 |

## 4. 总体布局

### 后台框架

- 左侧固定侧边栏宽度：`220px`。
- 右侧内容区背景为浅灰。
- 内容区 padding：`22px` 到 `24px`。
- 所有内容面板使用白底、浅边框、8px 圆角。

### 侧边栏菜单

菜单项：

- 首页概览。
- 老人档案。
- 二维码管理。
- 志愿者管理。
- 角色权限。
- 安全策略。
- 操作日志。

菜单项高度不小于 `40px`，选中项使用蓝绿色背景。

### 顶部安全提示

首页顶部必须展示安全能力提示：

```text
HTTPS · RBAC · AES-256 · IP 白名单
```

右侧使用锁或盾牌图标。

## 5. 页面复刻细节

### 5.1 后台登录页

- 居中登录卡片。
- 标题：“智联名牌管理后台”。
- 账号、密码输入框。
- “账号密码登录”按钮。
- 登录失败提示不得暴露账号是否存在。

### 5.2 管理首页

统计卡片至少包含：

- 老人档案。
- 志愿者。
- 今日扫码。
- 验证通过。
- 异常访问可作为附加风险卡片。

卡片样式：

- 白底。
- 左上角图标。
- 指标名灰色。
- 数值大号加粗。
- 趋势或状态小号展示。

### 5.3 老人档案管理

表格列：

- 档案编号。
- 姓名。
- 年龄。
- 联系电话，必须脱敏。
- 负责志愿者。
- 状态。

要求：

- 表头浅灰底。
- 行高不小于 `44px`。
- 状态用标签展示。
- 不展示完整手机号。

### 5.4 二维码管理

页面必须明确展示：

```text
二维码不包含明文身份和健康信息，仅保存加密 token。
```

功能区：

- 生成二维码。
- 绑定老人档案。
- 停用二维码。
- 重新生成二维码。

状态：

- 启用。
- 已停用。
- 已重新生成。

### 5.5 RBAC 权限配置

必须展示角色：

- 志愿者。
- 项目管理员。
- 审计员。
- 系统管理员。

权限维度：

- 菜单权限。
- 接口权限。
- 数据范围。
- 导出权限。

建议使用权限矩阵或分组列表，不使用纯文本长段落。

### 5.6 安全策略页

安全模块必须可见：

- HTTPS。
- 微信 OpenID。
- JWT 短时 Token。
- 短信二次验证。
- AES-256 加密。
- 接口签名。
- IP 白名单。
- 操作日志。

每个模块用安全卡片展示，包含状态、说明、配置入口。

### 5.7 操作日志页

日志字段：

- 操作时间。
- 操作人。
- 操作类型。
- 操作对象。
- 来源 IP。
- 结果。

筛选条件：

- 时间范围。
- 操作人。
- 操作类型。
- 结果。
- 来源 IP。

失败或异常访问使用风险色标签。

## 6. 组件样式

| 组件 | 样式要求 |
| --- | --- |
| 侧边栏 | 深色背景、白色文字、选中项蓝绿色 |
| 面板 | 白底、8px 圆角、浅边框 |
| 统计卡片 | 图标 + 指标名 + 大数字 + 趋势 |
| 表格 | 浅灰表头、44px 行高、分割线清晰 |
| 状态标签 | 小圆角标签，颜色区分成功/失败/停用 |
| 权限矩阵 | 角色为行，权限维度为列 |
| 日志列表 | 支持筛选，结果标签清晰 |

## 7. 禁止出现

- 炫酷大屏、3D 图表、营销 hero。
- 未脱敏手机号。
- 全员可见所有老人身份信息的暗示。
- 健康检测、实时监测、诊断、预约、聊天模块。

## 8. UI 验收标准

- 与概念图一致：深色侧边栏、白色面板、蓝绿色安全主色。
- 后台首页能一眼看到统计、档案表格、权限/日志入口。
- 二维码管理页明确体现“加密 token，不存明文”。
- RBAC 和操作日志页面能支撑答辩说明。
- 1366px 宽度下不横向溢出。
- 表格内容、按钮文字、标签文字不重叠。
