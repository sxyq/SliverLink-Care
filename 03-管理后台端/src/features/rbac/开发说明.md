# rbac 功能开发说明

## 目录职责

`features/rbac` 管理后台前端 RBAC 展示和交互。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `permissionGuard.ts` | 菜单、按钮权限判断 | 已完成（前端展示控制已体现在 Sidebar 和各页面） |
| `rolePermissionModel.ts` | 角色、权限、数据范围模型 | 已完成（类型定义在 types/index.ts，数据在 data/mockAdminData.ts） |

## 安全说明

前端权限判断只控制展示，后端必须校验接口权限和数据范围。
