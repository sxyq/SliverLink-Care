# api 目录开发说明

## 目录职责

`api` 存放管理后台对统一后端的接口封装。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `httpClient.ts` | 统一请求封装，携带 JWT、接口签名字段 | 已完成（功能已合并到 adminApi.ts 中的 delay 模拟） |
| `adminApi.ts` | 登录、首页统计、老人档案、志愿者管理 | 已完成 |
| `qrcodeApi.ts` | 二维码生成、停用、重新生成 | 已完成（Mock 数据直接放在 data/mockAdminData.ts） |
| `rbacApi.ts` | 角色、权限、数据范围接口 | 已完成（Mock 数据直接放在 data/mockAdminData.ts） |
| `auditApi.ts` | 操作日志查询、筛选、导出 | 已完成（Mock 数据直接放在 data/mockAdminData.ts） |
