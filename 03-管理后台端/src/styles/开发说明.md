# styles 目录开发说明

## 目录职责

`styles` 存放后台主题和布局样式。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `theme.css` | 后台颜色、字号、间距变量 | 已完成 |
| `admin-layout.css` | 侧边栏、顶部栏、表格、面板布局 | 已完成 |

## 概念图样式复刻参数

| 样式项 | 规范 |
| --- | --- |
| 页面背景 | `#EEF2F5` |
| 侧边栏 | `#132C3A` |
| 菜单选中 | `#1C7488` |
| 主色 | `#115F72` |
| 成功色 | `#0A8067` |
| 风险色 | `#C2410C` |
| 主文本 | `#17212B` |
| 次文本 | `#687989` |
| 边框 | `#D9E2E8` |
| 侧边栏宽度 | `220px` |
| 内容区 padding | `22px` 到 `24px` |
| 面板圆角 | 不超过 `8px` |
| 表格行高 | 不小于 `44px` |

禁止做成炫酷大屏、营销 hero、3D 图表或单色深蓝科技风。
