# components 目录开发说明

## 目录职责

`components` 存放后台通用组件。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `Sidebar.tsx` | 后台菜单 | 已完成 |
| `MetricCard.tsx` | 首页统计卡片 | 已完成 |
| `DataTable.tsx` | 通用数据表格 | 已完成（样式已合并到 admin-layout.css，页面直接使用 data-table 类） |
| `StatusTag.tsx` | 启用、停用、成功、失败状态 | 已完成 |
| `PermissionMatrix.tsx` | RBAC 权限矩阵 | 已完成 |

## 概念图组件复刻细节

### `Sidebar.tsx`

- 宽度固定 `220px`。
- 背景色 `#132C3A`。
- 菜单选中项背景色 `#1C7488`。
- 菜单项高度不小于 `40px`。

### `MetricCard.tsx`

- 白底、浅边框、`8px` 圆角。
- 结构为图标、指标名、加粗大数字、趋势说明。

### `DataTable.tsx`

- 表头浅灰底。
- 行高不小于 `44px`。
- 单元格左右 padding 不小于 `12px`。
- 表格中手机号、联系人必须接收脱敏后的值。

### `StatusTag.tsx`

- 成功/启用使用绿色。
- 停用使用灰色。
- 失败/异常访问使用风险色。

### `PermissionMatrix.tsx`

- 角色作为行，权限维度作为列。
- 志愿者、项目管理员、审计员、系统管理员四类角色必须可展示。
