# types 目录开发说明

## 目录职责

`types` 存放后台 TypeScript 类型。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `admin.ts` | 后台首页统计、管理员信息 | 已完成（合并到 types/index.ts） |
| `qrcode.ts` | 二维码生成、状态、访问 URL 类型 | 已完成（合并到 types/index.ts） |
| `rbac.ts` | 角色、权限、数据范围类型 | 已完成（合并到 types/index.ts） |
| `audit.ts` | 操作日志类型 | 已完成（合并到 types/index.ts） |
