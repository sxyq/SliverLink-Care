# 志愿者填写端 UI 复刻规范

## 1. 视觉基准

基准概念图：

```text
D:\Project\SilverLink Care\ui_overview_images\new_02_volunteer_entry_overview.png
```

该图包含 5 个界面：志愿者登录页、本人负责老人列表、基本信息编辑页、健康档案填写页、量表填写页。开发时要把这些界面拆成真实 H5 页面。

## 2. 整体风格

- 风格：社区随访录入工具，专业、清晰、高效。
- 页面基调：白色表单卡片 + 浅蓝绿背景。
- 信息密度：比扫码端更高，但不能像 Excel 表格一样拥挤。
- 重点：本人负责老人、表单录入、保存提交、权限边界。

## 3. 颜色规范

| 用途 | 颜色建议 | 用法 |
| --- | --- | --- |
| 页面背景 | `#EDF5F7` | 移动端整体背景 |
| 主色 | `#126B78` | 登录按钮、提交按钮、选中 chip |
| 权限提示色 | `#0A8067` | “仅显示本人负责老人” |
| 警示色 | `#D77B25` | 需复核、短信验真提示 |
| 文本主色 | `#18222D` | 标题、表单值 |
| 文本次色 | `#5F6F7A` | 字段名、说明 |
| 边框色 | `#D8E7EA` | 输入框、卡片边框 |

## 4. 页面布局

### 4.1 登录页

- 页面居中显示登录卡片。
- 登录卡片宽度：手机端 `calc(100% - 40px)`，最大 `420px`。
- 卡片内从上到下为：图标、标题、账号输入框、密码输入框、登录按钮。
- 登录按钮高度不小于 `44px`。

### 4.2 本人负责老人列表

顶部必须显示：

```text
仅显示本人负责老人
社区随访填写
```

列表项内容：

- 老人姓名。
- 档案编号。
- 年龄。
- 最近随访日期。
- 状态：待随访、已完成、需复核。

列表项样式：

- 白底或浅色底。
- 选中项使用浅绿色背景和主色边框。
- 每项最小高度 `64px`，方便触控。

### 4.3 基本信息编辑页

表单字段：

- 姓名。
- 性别。
- 年龄。
- 紧急联系人姓名。
- 紧急联系人电话。
- 联系人与老人关系。
- ABO 血型。
- Rh 血型。
- 过敏史。

样式要求：

- 表单分组展示，不做密集表格。
- 两列字段用于短字段，长字段独占整行。
- 修改紧急联系人电话时出现“短信验真”提示。

### 4.4 健康档案填写页

字段：

- 身高。
- 体重。
- 腰围。
- BMI。
- 健康状态自评。
- 生活自理能力自评。
- 认知功能。
- 情感状态。

交互：

- BMI 自动计算，输入框只读。
- 自评类字段使用 chip 或 segmented control。
- 提交按钮固定在表单底部，颜色使用主色。

### 4.5 主要用药填写区

用药不使用大表格，采用“药品记录卡片”：

- 药物名称。
- 用量。
- 用法。
- 用药时间。
- 新增/删除按钮。

每条药品记录边框清晰，字段间距充足。

### 4.6 量表填写页

量表页面以题目卡片展示：

- PHQ-9。
- GAD-7。
- UCLA。

每题展示：

- 题号。
- 问题文本。
- 0/1/2/3 或对应文字选项 chip。

要求：

- 未答题要有明显提示。
- 页面底部显示当前完成度和总分。
- 必须说明量表只作为随访记录，不作为诊断结论。

## 5. 组件样式

| 组件 | 样式要求 |
| --- | --- |
| 表单卡片 | 白底、8px 圆角、浅边框、轻阴影 |
| 输入框 | 42px 到 44px 高，8px 圆角 |
| 选项 chip | 未选中浅色底，选中主色底白字 |
| 老人列表项 | 可点击卡片，选中态明显 |
| 提交按钮 | 主色背景、白字、保存图标 |
| 权限提示 | 绿色文字，锁或盾牌图标 |

## 6. 禁止出现

- 全量老人查询入口。
- 越权查看全部身份信息。
- 健康检测、实时监测、诊断、预约、聊天模块。
- 过度复杂的数据分析图表。

## 7. UI 验收标准

- 页面整体与概念图一致：移动端表单型工具，白底卡片，蓝绿色主色。
- 志愿者权限提示必须在列表页首屏可见。
- 健康档案表单可在手机宽度 `375px` 下正常阅读和填写。
- 量表题目和选项不拥挤、不重叠。
- 提交和保存按钮醒目。
