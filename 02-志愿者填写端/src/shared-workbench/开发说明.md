# shared-workbench 开发说明

## 目录职责

本目录是照护工作台的共享源码目录。

目标：
- 去掉家属端与志愿者端重复的老人工作台页面
- 保留一份共享实现

## 当前服务对象

- 志愿者入口
- 家属入口

## 文件说明

| 文件 | 功能 |
| --- | --- |
| `types.ts` | 共享工作台模型 |
| `SubjectListPage.tsx` | 通用老人列表 |
| `SubjectDetailPage.tsx` | 通用老人详情 |
| `MedicationEditorPage.tsx` | 通用用药编辑 |

## 使用原则

共享组件只负责：
- UI 骨架
- 通用交互

共享组件不负责：
- 登录逻辑
- 权限判断
- 邀请码注册
- 健康档案与量表专属逻辑
