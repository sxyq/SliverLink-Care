# styles 目录开发说明

## 目录职责

`styles` 存放志愿者端主题和表单样式。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `theme.css` | 颜色、字号、间距变量 |
| `form.css` | 表单、选项、提交栏样式 |

## 概念图样式复刻参数

| 样式项 | 规范 |
| --- | --- |
| 页面背景 | `#EDF5F7` |
| 主色 | `#126B78` |
| 权限提示色 | `#0A8067` |
| 警示色 | `#D77B25` |
| 主文本 | `#18222D` |
| 次文本 | `#5F6F7A` |
| 边框 | `#D8E7EA` |
| 卡片圆角 | 不超过 `8px` |
| 输入框高度 | `42px` 到 `44px` |
| 老人列表项高度 | 不小于 `64px` |

整体必须保持移动端表单工具风格，不做营销页、插画页或大屏风。
