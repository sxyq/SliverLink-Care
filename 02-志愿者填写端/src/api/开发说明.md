# api 目录开发说明

## 目录职责

`api` 存放志愿者端后端接口封装。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `httpClient.ts` | 统一请求封装，附带志愿者 JWT |
| `volunteerApi.ts` | 登录、本人负责老人列表接口 |
| `elderApi.ts` | 基本信息、健康档案、用药、量表提交接口 |
| `smsApi.ts` | 修改身份信息时的短信验证码接口 |

## 接口约束

- 所有老人数据接口必须由后端校验志愿者负责范围。
- 前端只做体验提示，不能作为安全边界。
