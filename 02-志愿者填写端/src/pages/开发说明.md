# pages 目录开发说明

## 目录职责

`pages` 存放志愿者填写端页面组件。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `LoginPage.tsx` | 志愿者登录页 |
| `AssignedElderListPage.tsx` | 本人负责老人列表 |
| `BasicInfoFormPage.tsx` | 老人基本信息编辑 |
| `HealthRecordFormPage.tsx` | 健康档案填写 |
| `MedicationFormPage.tsx` | 主要用药填写 |
| `ScaleFormPage.tsx` | PHQ-9、GAD-7、UCLA 量表填写 |

## 概念图复刻要求

本目录下页面必须按 `D:\Project\SilverLink Care\ui_overview_images\new_02_volunteer_entry_overview.png` 的志愿者端界面复刻。

### `LoginPage.tsx`

- 居中显示登录卡片，卡片包含图标、标题“志愿者登录”、账号输入框、密码输入框、登录按钮。
- 登录按钮高度不小于 `44px`，使用蓝绿色主色。

### `AssignedElderListPage.tsx`

- 顶部必须显示权限提示：“仅显示本人负责老人”。
- 页面标题使用“社区随访填写”。
- 老人列表项必须展示姓名、档案编号、年龄、最近随访日期、状态。
- 选中老人列表项使用浅绿色背景和主色边框。

### `BasicInfoFormPage.tsx`

- 表单分组展示，不使用密集表格。
- 姓名、性别、年龄等短字段可两列布局。
- 紧急联系人电话修改区域必须显示“短信验真”提示。

### `HealthRecordFormPage.tsx`

- 健康档案字段使用白底表单卡片。
- 身高、体重、腰围为输入框，BMI 为自动计算只读字段。
- 健康状态自评、生活自理能力、认知功能、情感状态使用 chip 或 segmented control。

### `MedicationFormPage.tsx`

- 用药记录使用药品卡片，不使用 Excel 式大表格。
- 每条记录包含药物名称、用量、用法、用药时间、新增/删除操作。

### `ScaleFormPage.tsx`

- 每道题使用题目卡片。
- 选项使用 0/1/2/3 或对应文字 chip。
- 页面底部展示完成度和总分。
- 必须显示“量表只作为随访记录，不作为诊断结论”。
