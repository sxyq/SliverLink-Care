# components 目录开发说明

## 目录职责

`components` 存放志愿者端表单和列表通用组件。

## 状态：已完成

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `ElderListItem.tsx` | 本人负责老人列表项 |
| `FormSection.tsx` | 表单分组容器 |
| `TextInput.tsx` | 文本/数字输入框 |
| `SelectChips.tsx` | 选项型字段选择 |
| `ScaleQuestion.tsx` | 量表单题填写组件 |
| `SubmitBar.tsx` | 保存草稿、提交按钮区 |

## 设计要求

- 表单适合手机端录入。
- 必填、错误、草稿、提交状态清晰。

## 概念图组件复刻细节

### `ElderListItem.tsx`

- 最小高度 `64px`。
- 展示姓名为主标题，档案编号、年龄、状态为次信息。
- 选中态使用浅绿色背景和 `#126B78` 边框。

### `FormSection.tsx`

- 白底、浅边框、`8px` 圆角。
- 标题左侧可放图标。
- 分组之间间距 `14px` 到 `16px`。

### `TextInput.tsx`

- 高度 `42px` 到 `44px`。
- 圆角 `8px`。
- 错误态使用橙色或红色边框，并显示简短错误文案。

### `SelectChips.tsx`

- 未选中为浅色底、主色文字。
- 选中为主色底、白色文字。
- chip 间距不小于 `8px`。

### `ScaleQuestion.tsx`

- 题号和题目文本必须清晰分层。
- 选项按钮不能拥挤，手机宽度下允许换行。

### `SubmitBar.tsx`

- 主提交按钮使用 `#126B78`。
- 可同时提供保存草稿按钮，但视觉层级低于提交按钮。
