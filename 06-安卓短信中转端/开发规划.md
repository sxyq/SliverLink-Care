# 安卓短信中转端开发规划

## 1. 当前状态

`06-安卓短信中转端` 已完成第一版正式实现，不再是项目骨架。

当前已经具备：

- Android Gradle Wrapper
- `assembleDebug` 构建能力
- Material 3 三页 UI
- 短信接收广播
- 短信上传 Worker
- 设备心跳 Worker
- 本地配置和状态持久化
- 对统一后端 `smsrelay` 模块的接口封装

## 2. 目标

把固定安卓设备作为“短信接收与回传终端”长期部署，用于：

- 接收用户发往固定号码的验证码短信
- 解析手机号和短信内容
- 将数据安全回传到统一后端
- 支撑扫码端和统一照护工作台中的敏感信息查看验证

## 5. 关键文件职责

### `RelayApplication.kt`

- 应用入口
- 负责 WorkManager 初始化
- 后续应补首次心跳调度

### `MainActivity.kt`

- 宿主 Activity
- 承载底部导航
- 管理总览 / 记录 / 设置三个 Fragment 切换

### `receiver/SmsReceiver.kt`

- 监听系统短信广播
- 解析发件号码与短信正文
- 将记录交给 Worker / Repository

### `receiver/BootCompletedReceiver.kt`

- 设备重启后恢复后台任务
- 用于重建心跳链路

### `worker/InboundSmsUploadWorker.kt`

- 上传短信记录
- 更新上传状态
- 失败后走重试

### `worker/HeartbeatWorker.kt`

- 定时向服务器上报设备心跳
- 更新最近在线状态

### `repository/SmsRelayRepository.kt`

- 保存 `SmsRecord`
- 管理状态流转
- 统计成功、失败、待重试数量

### `data/local/RelayPreferences.kt`

- 保存固定接收号码
- 保存服务器地址
- 保存设备 ID / 密钥
- 保存最近同步时间、运行时长、统计信息

### `data/network/RelayApiService.kt`

- `POST /api/sms-relay/inbound`
- `POST /api/sms-relay/heartbeat`
- `GET /api/sms-relay/devices/{deviceId}/config`

## 7. 与统一后端的对接规划

后端对应目录：

- [04-统一后端/src/main/java/com/silverlink/care/module/smsrelay](</D:/Project/SilverLink Care/04-统一后端/src/main/java/com/silverlink/care/module/smsrelay>)

安卓端负责：

- 接收短信
- 上传原始记录
- 发送设备心跳
- 获取设备配置

后端负责：

- 会话校验
- 设备鉴权
- 审计留痕
- 决定是否放行敏感信息查看
