## 当前资源结构

| 目录 | 用途 |
| --- | --- |
| `layout/` | Activity、Fragment、列表项布局 |
| `drawable/` | 图标和状态圆点 |
| `menu/` | 底部导航菜单 |
| `values/` | 字符串、颜色、主题 |
| `xml/` | 备份规则、网络安全配置 |

## 关键资源说明

### `layout/activity_main.xml`

- 主容器布局
- 包含 Fragment 容器和底部导航

### `layout/fragment_overview.xml`

- 总览页布局

### `layout/fragment_records.xml`

- 记录页布局

### `layout/fragment_settings.xml`

- 设置页布局

### `layout/item_metric.xml`

- 总览页统计指标卡

### `layout/item_record.xml`

- 记录页短信记录项

### `values/colors.xml`

当前已扩展为完整状态色集合，用于：

- 主色
- 成功
- 失败
- 待重试
- 背景
- 文本层级

### `values/themes.xml`

- Material 3 主题
- 控制卡片、按钮、输入框样式

### `xml/network_security_config.xml`

- 预留服务器通信安全配置
- 用于调试和后续 HTTPS 切换
