# java/com/silverlink/smsrelay 开发说明

## 当前状态

本目录承载安卓短信中转端的主实现代码。

更完整的阶段总结、验证结果和剩余事项，请以：

- `05-安卓短信中转端/README.md`
- `05-安卓短信中转端/开发规划.md`

为准。

## 当前主线

- `service/` 负责后台常驻、心跳、短信上传主链路
- `receiver/` 负责短信广播接收与开机恢复
- `repository/` 负责本地记录和上传状态流转
- `data/` 负责配置、模型和网络请求
- `ui/` 负责总览、记录、设置三页
- `util/` 负责短信解析、签名辅助、配置合并和系统保活辅助

## 当前实现重点

- 主链路已经切换到前台服务模式
- `SmsReceiver` 已接入 `SmsParser`
- 设置页已支持短信权限与息屏保活引导
- 总览页和设置页已展示后台服务状态
