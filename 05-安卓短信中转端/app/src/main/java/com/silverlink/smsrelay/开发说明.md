# java/com/silverlink/smsrelay 开发说明

## 当前状态

本目录已经不是占位代码目录，而是安卓短信中转端的主实现目录。

## 目录职责

| 文件 / 目录 | 职责 |
| --- | --- |
| `RelayApplication.kt` | 应用入口，初始化全局依赖和任务系统 |
| `MainActivity.kt` | 承载底部导航和三个 Fragment |
| `receiver/` | 短信接收、开机恢复 |
| `worker/` | 上传、重试、心跳 |
| `repository/` | 本地记录、接口调用、统计聚合 |
| `data/local/` | 配置和状态持久化 |
| `data/model/` | 短信记录、设备状态、上传状态模型 |
| `data/network/` | API 客户端和中转接口 |
| `ui/` | 总览 / 记录 / 设置页面实现 |
| `util/` | 短信解析等工具逻辑 |

## 关键实现说明

### `MainActivity.kt`

- 负责底部导航
- 负责 Overview / Records / Settings 三页切换
- 不承载短信解析和上传逻辑

### `ui/overview/OverviewFragment.kt`

- 展示设备在线状态
- 展示固定接收手机号、服务器地址、设备 ID
- 展示统计指标和最近短信

### `ui/records/RecordsFragment.kt`

- 展示短信记录列表
- 支持按上传状态筛选
- 负责失败 / 待重试状态可视化

### `ui/settings/SettingsFragment.kt`

- 维护固定接收号码
- 维护服务器地址、设备 ID、设备密钥
- 展示最近心跳、最近同步和版本信息

### `receiver/SmsReceiver.kt`

- 接收短信广播
- 提取发送方手机号和短信正文
- 调用 `SmsParser` 解析验证码格式
- 将记录交给 Repository / Worker

### `worker/InboundSmsUploadWorker.kt`

- 读取待上传记录
- 回传到 `/api/sms-relay/inbound`
- 更新状态为 `UPLOADED / FAILED / RETRYING`

### `worker/HeartbeatWorker.kt`

- 调用 `/api/sms-relay/heartbeat`
- 更新设备心跳时间

### `repository/SmsRelayRepository.kt`

- 保存 `SmsRecord`
- 管理状态流转
- 统计成功、失败、待重试数量

## 当前已知未完成项

- 真机接收短信验证
- 运行时权限引导
- 自定义退避策略
- 首次启动自动心跳
