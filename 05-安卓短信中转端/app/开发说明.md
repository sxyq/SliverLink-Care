# app 模块开发说明

## 当前状态

`app` 是安卓短信中转端的唯一应用模块，当前已经具备可构建、可安装、可继续联调的实现基础。

## 模块职责

- 提供 Material 3 风格主界面
- 接收系统短信广播
- 保存设备配置和本地记录
- 组织短信上传与心跳任务
- 输出调试 APK

## 已落地页面

- 总览页
- 记录页
- 设置页

页面由 [MainActivity.kt](</D:/Project/SilverLink Care/06-安卓短信中转端/app/src/main/java/com/silverlink/smsrelay/MainActivity.kt>) 承载，并通过底部导航切换。

## 与业务链路的关系

`app` 本身不决定“是否允许查看健康档案”，它只负责：

- 接收短信
- 回传数据
- 展示设备状态

真正的验证放行由统一后端完成。

## 当前构建状态

- `gradlew assembleDebug` 已通过
- 调试包位于：
  - [app-debug.apk](</D:/Project/SilverLink Care/06-安卓短信中转端/app/build/outputs/apk/debug/app-debug.apk>)

## 当前边界

- 不把业务放行逻辑写入 Activity
- 不在 BroadcastReceiver 中直接写复杂网络逻辑
- 不在 UI 层维护原始上传协议
- 所有上传、重试、状态更新统一走 Repository 和 Worker
