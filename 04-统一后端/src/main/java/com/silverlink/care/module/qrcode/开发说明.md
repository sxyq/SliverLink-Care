# qrcode 模块开发说明

## 目录职责

`qrcode` 模块负责二维码生成、加密 token、绑定老人档案、扫码解析、停用和重新生成。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `QrCodeController.java` | 二维码生成、停用、重新生成、扫码解析接口 |
| `QrCodeService.java` | 生成加密二维码 token、绑定老人档案、停用二维码 |
| `QrCodeEntity.java` | 二维码实体，包含 id、elderId、qrTokenHash、status、keyId、createdAt、disabledAt |
| `QrCodeMapper.java` | 二维码表数据库访问 |
| `dto/QrCodeCreateRequest.java` | 后台生成二维码请求 |
| `dto/QrCodeCreateResponse.java` | 返回二维码访问 URL、二维码图片 base64 或文件地址 |
| `dto/QrResolveResponse.java` | 扫码解析结果 |

## 加密方案

二维码 URL：

```text
https://demo-domain.example.com/s/{encryptedQrToken}
```

加密前 payload：

```json
{
  "qrId": "QR202605210001",
  "elderId": "ELDER001",
  "issuedAt": "2026-05-21T16:00:00+08:00",
  "version": 1
}
```

规则：

- 使用 AES-256-GCM。
- 每次生成 12 字节随机 IV。
- Token 结构为 `kid.iv.ciphertext.tag`。
- 每段使用 base64url 编码。
- 服务端保存 token hash，不保存明文 token。
- 二维码停用后必须拒绝访问。

## 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/admin/qrcodes` | 生成二维码 |
| `PUT /api/admin/qrcodes/{id}/disable` | 停用二维码 |
| `POST /api/admin/qrcodes/{id}/regenerate` | 重新生成二维码 |
| `POST /api/scan/resolve` | 扫码解析二维码 |

## 支撑前端 UI 复刻的返回字段

二维码管理页需要展示以下字段：

- `qrId`
- `elderId`
- `archiveNo`
- `status`
- `publicUrl`
- `qrImageBase64` 或 `qrImageUrl`
- `encryptedTokenPreview`
- `securityNote`

`securityNote` 固定表达二维码安全口径：

```text
二维码不包含明文身份和健康信息，仅保存加密 token。
```

前端只展示 token 前后片段，不展示完整 token。

## 与实体名牌 PDF 的关系

- 实体名牌背面的二维码必须由本模块生成。
- PDF 模块不得自行拼接明文老人信息到二维码。
- PDF 模块只接收 `publicUrl` 或二维码图片数据，不接收完整健康档案、用药、量表数据。
