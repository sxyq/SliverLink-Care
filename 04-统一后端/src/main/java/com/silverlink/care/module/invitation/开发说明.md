# invitation 模块开发说明

## 状态：已完成

## 1. 模块定位

`invitation` 模块负责后台生成家属邀请码，家属通过邀请码注册协管账号。

邀请码用于建立“家属账号 - 老人档案”的绑定关系。

## 2. 建议文件

```text
invitation/
  InvitationController.java
  InvitationService.java
  InvitationEntity.java
  InvitationMapper.java
  dto/
    InvitationCreateRequest.java
    InvitationCreateResponse.java
    InvitationPreviewResponse.java
    FamilyRegisterByInvitationRequest.java
```

## 3. 后台接口

```text
GET  /api/admin/invitations
POST /api/admin/invitations
PUT  /api/admin/invitations/{id}/disable
DELETE /api/admin/invitations/{id}
GET  /api/admin/family-bindings
PUT  /api/admin/family-bindings/{id}/disable
```

## 4. 家属注册接口

```text
GET  /api/invitations/{code}/preview
POST /api/invitations/{code}/send-sms
POST /api/invitations/{code}/register
```

## 5. 邀请码规则

- 邀请码必须绑定一个老人档案。
- 默认有效期 7 天。
- 默认一次性使用；如需多人协管，可配置最大使用次数。
- 邀请码只显示绑定老人摘要，敏感信息脱敏。
- 注册时必须短信验证家属手机号。
- 注册成功后邀请码状态改为已使用或使用次数加一。
- 后台可作废邀请码。

## 7. 审计日志

以下行为必须记录：

- 后台生成邀请码。
- 后台作废邀请码。
- 家属预览邀请码。
- 家属短信验证。
- 家属注册成功。
- 后台解绑家属账号。
