# volunteer 模块开发说明

## 模块职责

`volunteer` 模块负责统一照护工作台中“志愿者账号模式”的后端接口。

前端虽然已经与家属账号模式共用一套工作台实现，但这里仍然是独立的志愿者账号体系。

## 主要职责

- 志愿者登录
- 获取本人负责老人列表
- 返回志愿者工作台详情所需字段
- 配合 `elder` 模块完成基本信息、健康档案、用药、量表提交

## 权限原则

志愿者账号只能访问：

- 本人负责老人

志愿者账号不能访问：

- 非负责老人
- 家属绑定但不在本人范围内的数据
- 后台管理接口

## 与统一工作台的关系

前端当前已经把以下页面抽成共用工作台：

- 老人列表
- 老人详情
- 用药维护

因此本模块返回字段必须稳定支撑这些共用页面的渲染。
