# sms 模块开发说明

## 模块职责

`sms` 模块不再默认代表“云短信验证码下发”，而是负责短信验证领域的通用能力抽象。

当前项目正式方案是：

- 固定号码短信回传验证
- 安卓短信中转端接收并回传
- 后端完成验证放行

因此 `sms` 模块需要与新增的 `smsrelay` 模块配合：

- `sms`：保留验证领域通用规则
- `smsrelay`：承接当前正式回传链路

## 当前文件职责

| 文件 | 代码功能 |
| --- | --- |
| `SmsController.java` | 保留兼容性短信接口入口和过渡逻辑 |
| `SmsService.java` | 验证规则、时效、重试、短时授权策略 |
| `SmsProvider.java` | 未来接云短信平台时的抽象接口 |
| `MockSmsProvider.java` | 仅限本地或历史兼容调试，不再作为正式路径 |

## 更新后的业务规则

- 正式版本优先使用 `smsrelay` 验证会话
- `sms` 模块不再向前端承诺“系统向用户下发验证码”
- 若未来接阿里云/腾讯云，可由 `SmsProvider` 作为备用路径
