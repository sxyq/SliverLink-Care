# admin 模块开发说明

## 目录职责

`admin` 模块为管理后台提供聚合 API。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `AdminController.java` | 管理首页、老人档案、二维码、志愿者管理入口 |
| `AdminDashboardService.java` | 统计老人数量、志愿者数量、扫码次数、验证次数、异常访问 |
| `dto/DashboardResponse.java` | 后台首页统计响应 |

## 注意事项

具体业务可委托 elder、qrcode、volunteer、rbac、audit 模块完成。

## 支撑后台 UI 复刻的响应字段

`DashboardResponse.java` 需要支持后台概念图中的统计卡片：

- `elderCount`
- `volunteerCount`
- `todayScanCount`
- `todaySmsVerifiedCount`
- `abnormalAccessCount`

后台档案列表响应必须返回脱敏手机号字段，不返回完整手机号给普通列表页。
