# elder 模块开发说明

## 目录职责

`elder` 模块管理老人基础档案、健康档案、主要用药、量表记录。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `ElderController.java` | 老人档案相关接口 |
| `ElderService.java` | 老人基本信息、健康档案、用药、量表统一业务 |
| `ElderEntity.java` | 老人基础档案实体 |
| `HealthRecordEntity.java` | 健康档案实体 |
| `MedicationEntity.java` | 主要用药实体 |
| `ScaleRecordEntity.java` | 量表记录实体 |
| `ElderMapper.java` | 数据库访问 |

## 数据安全

手机号、联系人、健康档案、用药、量表等敏感字段需要通过 `FieldEncryptor` 加密存储。
