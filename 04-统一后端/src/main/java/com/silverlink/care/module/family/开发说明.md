# family 模块开发说明

## 模块职责

`family` 模块负责统一照护工作台中“家属账号模式”的后端接口。

注意：

- 前端已经不再保留独立家属工程
- 家属账号与志愿者账号共用统一照护工作台前端
- 但后端接口和权限判断不能与志愿者账号混用

## 主要职责

- 家属登录
- 获取当前账号绑定老人列表
- 获取绑定老人详情
- 更新联系人信息
- 查询二维码信息
- 家属侧用药维护

## 权限原则

家属账号只能访问：

- 与自己绑定的老人

家属账号不能访问：

- 非绑定老人
- 志愿者负责但未绑定给本账号的老人
- 健康档案和量表填写后台接口
- 志愿者管理或后台管理接口
