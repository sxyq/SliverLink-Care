# nameplate 模块开发说明

## 目录职责

`nameplate` 模块负责根据老人基础信息和加密二维码生成实体名牌预览与 PDF。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `NameplateController.java` | 提供名牌预览、单个 PDF 下载、批量 PDF 生成接口 |
| `NameplateService.java` | 组装老人基础信息、二维码图片、名牌模板数据 |
| `NameplateTemplateConfig.java` | 定义可由服务端模板文件调整的视觉参数 |
| `NameplatePdfRenderer.java` | 将名牌模板渲染为 PDF 文件 |
| `dto/NameplatePreviewResponse.java` | 返回前端预览所需的正反面字段、二维码预览图 |
| `dto/NameplatePdfRequest.java` | 批量生成 PDF 时的请求参数 |

## 名牌内容

正面：

- 品牌名“智联名牌”。
- 品牌副标题“智护空巢”。
- 姓名。
- 年龄。
- 联系电话。

背面：

- 品牌名“智联名牌”和品牌副标题“智护空巢”。
- 加密二维码。
- 健康档案编号。
- 扫码提示语。
- 底部归属文案“重庆医科大学空巢养老团”。

## 空白模板规则

当用于展示样图或未录入真实信息时：

- 姓名显示为空白横线。
- 年龄显示为空白横线。
- 联系电话显示为空白横线。
- 二维码区域使用占位二维码。
- 不出现真实个人信息。

## PDF 生成规则

- PDF 不包含健康档案、用药情况、量表记录。
- 二维码必须来自 `qrcode` 模块生成的加密二维码。
- PDF 页面应包含正面和背面两个版面。
- 后续支持批量生成多个老人名牌。

## 视觉模板热更新

PDF 下载和预览图共用 `NameplateService` 的服务端渲染结果。可通过环境变量
`SILVERLINK_NAMEPLATE_TEMPLATE_CONFIG_FILE` 指向外部 JSON 文件，调整以下内容：

- 字体资源路径。
- 背景波浪色、文字色、线条色、边框色和标记色。
- 姓名与年龄横线的位置、宽度、基线位置，以及“岁”的间距。

服务端会按文件修改时间重新读取模板，模板更新后新的 PDF 和预览图自动使用新参数。该范围只影响 PDF 和预览图片，不执行远程代码，也不改变小程序页面路由、登录或业务流程，因此不需要重新提交小程序审核。原生页面结构、交互和权限变化仍需按微信发布流程处理。

模板示例：

```json
{
  "fontResource": "/fonts/ArialUnicode.ttf",
  "ink": "#054A5F",
  "mutedInk": "#52727C",
  "mint": "#DEF1EE",
  "mintDeep": "#ACD5CF",
  "line": "#81B9B2",
  "gold": "#ECAE44",
  "border": "#D3E1E2",
  "careMark": "#378B82",
  "frontNameLineXRatio": 0.33,
  "frontLineWidth": 86,
  "frontNameBaselineRatio": 0.43,
  "frontAgeBaselineRatio": 0.30,
  "frontAgeUnitGap": 8
}
```

## API

| 接口 | 用途 |
| --- | --- |
| `GET /api/nameplates/{elderId}/preview` | 获取名牌预览数据 |
| `GET /api/nameplates/{elderId}/pdf` | 下载单个老人名牌 PDF |
| `POST /api/nameplates/batch-pdf` | 批量生成名牌 PDF |
