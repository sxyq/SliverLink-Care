# scan 模块开发说明

## 目录职责

`scan` 模块为扫码用户端提供 API。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `ScanController.java` | 提供扫码解析、健康档案、用药、量表查看接口 |
| `ScanService.java` | 解密二维码 token、校验二维码状态、返回基础信息、校验短信授权后返回敏感信息 |
| `dto/ScanBasicInfoResponse.java` | 基础救助信息响应，手机号脱敏 |
| `dto/ProtectedArchiveResponse.java` | 健康档案、用药、量表综合响应 |

## 扫码流程

1. 前端提交 `encryptedQrToken`。
2. 后端调用 qrcode 模块解密和校验。
3. 返回老人基础信息。
4. 查看敏感信息前检查短信验证授权。
5. 记录扫码、查看、失败日志。

## 支撑前端 UI 复刻的响应字段

`ScanBasicInfoResponse.java` 必须支持扫码端概念图中的首屏字段：

- `archiveNo`
- `name`
- `gender`
- `age`
- `emergencyContactName`
- `emergencyPhoneMasked`
- `relationship`
- `aboType`
- `rhType`
- `allergySummary`
- `requiresVerification`
- `qrStatus`

`ProtectedArchiveResponse.java` 必须支持验证后 UI 状态：

- `verifiedAt`
- `verificationMethod`
- `healthRecord`
- `medications`
- `scaleSummaries`
- `diagnosisDisclaimer`

后端必须返回脱敏电话，前端不应自己从完整手机号生成展示值。
