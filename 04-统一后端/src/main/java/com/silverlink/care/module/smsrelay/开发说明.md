# smsrelay 模块开发说明

## 模块定位

`smsrelay` 模块负责承接安卓短信中转端回传，是当前正式短信验证链路的后端接收层。

它处理的是：

- 安卓设备上传收到的短信记录
- 安卓设备心跳上报
- 安卓设备配置下发

它不直接替代 `sms` 模块的验证规则，而是与 `sms` 模块协同完成会话校验和放行。

## 当前文件职责

| 文件 | 职责 |
| --- | --- |
| `SmsRelayController.java` | 提供 inbound、heartbeat、device config 接口 |
| `SmsRelayService.java` | 处理中转记录、设备状态和回传业务逻辑 |
| `InboundSmsRequest.java` | 安卓端回传短信记录请求体 |
| `HeartbeatRequest.java` | 安卓设备心跳请求体 |
| `DeviceConfigDto.java` | 设备配置返回结构 |
| `SmsRelayRecordDto.java` | 中转记录返回结构 |

## 对外接口

```text
POST /api/sms-relay/inbound
POST /api/sms-relay/heartbeat
GET  /api/sms-relay/devices/{deviceId}/config
```

## 与其他模块的关系

- `smsrelay`：负责接收设备侧数据
- `sms`：负责验证码会话规则和放行策略
- `audit`：负责日志记录
