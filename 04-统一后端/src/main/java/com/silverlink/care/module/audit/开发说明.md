# audit 模块开发说明

## 目录职责

`audit` 模块负责操作日志记录、查询、筛选和导出。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `AuditLogController.java` | 操作日志查询、筛选、导出接口 |
| `AuditLogService.java` | 记录查看、提交、修改、删除、导出、登录失败等行为 |
| `AuditLogEntity.java` | 操作日志实体 |
| `AuditAspect.java` | 通过注解或切面自动记录关键操作 |

## 日志字段

操作人、角色、时间、来源 IP、操作对象、操作类型、操作结果、失败原因、requestId。
