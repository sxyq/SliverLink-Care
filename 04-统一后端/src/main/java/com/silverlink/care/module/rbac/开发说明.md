# rbac 模块开发说明

## 目录职责

`rbac` 模块负责角色、权限、数据范围配置。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `RoleController.java` | 角色、权限、数据范围配置接口 |
| `RbacService.java` | 角色权限分配、菜单权限、接口权限、数据范围权限 |
| `RoleEntity.java` | 角色实体 |
| `PermissionEntity.java` | 权限实体 |
| `UserRoleEntity.java` | 用户角色绑定实体 |

## 权限规则

- 志愿者只能访问本人负责老人。
- 项目管理员只能访问本项目数据。
- 审计员只能查看日志，不能修改业务数据。
- 系统管理员才能修改安全策略。
