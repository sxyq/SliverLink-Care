# security 模块开发说明

## 目录职责

`security` 存放鉴权、JWT、RBAC、接口签名相关代码。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `JwtTokenProvider.java` | 签发、解析、刷新 JWT 短时 Token |
| `SecurityConfig.java` | Spring Security 配置，定义公开接口和受保护接口 |
| `RbacPermissionEvaluator.java` | 校验菜单权限、接口权限、数据范围权限 |
| `CurrentUser.java` | 当前登录用户上下文 |
| `SignatureInterceptor.java` | 校验接口签名、时间戳、随机数，防重放 |

## 安全要求

- 后台、志愿者端必须登录后访问。
- 扫码端基础信息可公开访问，但敏感档案必须验证后访问。
- 高危接口必须校验签名和 IP 白名单。
