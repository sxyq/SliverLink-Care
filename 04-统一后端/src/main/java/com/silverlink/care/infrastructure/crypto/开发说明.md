# crypto 基础设施开发说明

## 目录职责

`infrastructure/crypto` 提供加密、解密、hash 能力。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `AesGcmCryptoService.java` | AES-256-GCM 加解密，用于二维码 token 和敏感字段 |
| `FieldEncryptor.java` | 手机号、联系人、健康档案、用药、量表字段加密/解密 |
| `HashService.java` | 二维码 token hash、手机号 hash、验证码 hash |

## 安全要求

- 密钥不写入代码。
- 支持 keyId。
- IV 每次随机生成。
- 解密失败不得返回内部错误细节。
