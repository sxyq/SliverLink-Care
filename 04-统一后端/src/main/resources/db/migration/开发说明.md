# db/migration 开发说明

## 目录职责

存放 Flyway 数据库迁移脚本。

## 计划文件

| 文件 | 代码功能 |
| --- | --- |
| `V1__init_schema.sql` | 创建老人、健康档案、用药、量表、志愿者、二维码、角色、权限、日志表 |
| `V2__seed_demo_data.sql` | 插入 demo 老人、志愿者、管理员、角色权限、二维码样例数据 |
| `V5__seed_admin_role_accounts.sql` | 放宽账号唯一约束，并补充 `admin/admin` 的志愿者和家属测试账号 |
| `V9__add_elder_residence.sql` | 给老人档案补充居住地加密字段，并为演示数据补齐默认居住地 |
| `V10__backfill_elder_residence_mock_data.sql` | 给历史模拟老人档案批量回填默认住址，保证各端可展示住址信息 |

## 注意事项

- 迁移脚本只向前追加，不覆盖历史脚本。
- demo 数据必须使用虚构身份信息。
