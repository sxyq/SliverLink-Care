# 统一后端 README

## 当前定位

统一后端是智联名牌系统的唯一 Spring Boot 服务，当前同时服务：

- 扫码用户端
- 统一照护工作台
  - 志愿者账号模式
  - 家属账号模式
- 管理后台
- 安卓短信中转端

这里不再存在“独立家属前端项目”对应的一套独立后端语义。前端已经合并为统一照护工作台，但后端仍然必须保留不同账号体系和权限边界。

## 当前核心职责

- 二维码解析与校验
- 老人基本信息、健康档案、用药、量表读写
- 志愿者账号登录与数据范围控制
- 家属邀请码注册、绑定老人、联系人和用药维护
- 管理后台档案、二维码、志愿者、邀请码、日志管理
- 安卓短信中转设备、回传记录、验证会话和审计链路

## 当前权限边界

- 志愿者：只处理本人负责老人
- 家属：只处理绑定老人
- 管理后台：按后台角色管理业务与审计
- 扫码访问用户：默认只能看基础信息，敏感信息必须走短信回传验证

## 当前正式验证方案

敏感信息查看使用：

`固定号码短信回传验证 + 安卓短信中转端 + 后端会话校验`

当前正式口径不再以“云短信验证码下发”作为主链路。

## 当前实现状态

`smsrelay` 当前已经具备：

- 设备配置初始化与数据库持久化
- 短信回传记录持久化
- 扫码验证会话持久化
- 严格设备密钥校验
- 管理后台短信中转接口鉴权收口

当前已不再是“纯内存态短信中转演示实现”。

## 当前仍未完成项

- 真实短信服务商 SDK 适配仍未接入，`module/sms` 里的 `ConfiguredSmsProvider` 还不能正式下发云短信
- `SignatureInterceptor` 已定义，但尚未正式注册进 Spring MVC 请求链
- 扫码微信鉴权仍是 demo 返回，不是正式微信 OAuth / OpenID 对接
- 短信中转设备管理、回传记录、验证会话的后台查询页仍未完整落地
- 生产安全配置仍需收口，包括 demo 默认密钥、默认 key id、默认设备密钥等运行时配置替换
