# 统一后端 README

## 当前定位

统一后端是智联名牌系统的唯一 Spring Boot 服务，当前同时服务：

- 扫码用户端
- 统一照护工作台
  - 志愿者账号模式
  - 家属账号模式
- 管理后台
- 安卓短信中转端

这里不再存在“独立家属前端项目”对应的一套独立后端语义。前端已经合并为统一照护工作台，但后端仍然必须保留不同账号体系和权限边界。

## 当前核心职责

- 二维码解析与校验
- 老人基本信息、健康档案、用药、量表读写
- 志愿者账号登录与数据范围控制
- 家属邀请码注册、绑定老人、联系人和用药维护
- 管理后台档案、二维码、志愿者、邀请码、日志管理
- 安卓短信中转设备、回传记录、验证会话和审计链路

## 当前权限边界

- 志愿者：只处理本人负责老人
- 家属：只处理绑定老人
- 管理后台：按后台角色管理业务与审计
- 扫码访问用户：默认只能看基础信息，敏感信息必须走短信回传验证

## 当前正式验证方案

敏感信息查看使用：

`固定号码短信回传验证 + 安卓短信中转端 + 后端会话校验`

当前正式口径不再以“云短信验证码下发”作为主链路。
