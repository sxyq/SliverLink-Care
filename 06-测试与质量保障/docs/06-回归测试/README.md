# 回归测试规划

## 测试目标

回归测试用于每次修复或部署前确认历史问题不复发。

## 近期专项回归

| 问题 | 回归方式 |
| --- | --- |
| 扫码验证后显示另一个老人 | 使用两个不同二维码分别验证，断言验证前后 elderId 一致 |
| 身份证错误却提示手机号错误 | 输入合法手机号和非法身份证，断言错误文案为身份证 |
| 二维码弹窗按钮不生效 | 测试复制链接、打开扫码页两个按钮 |
| 后台表格操作列被遮挡 | 桌面、窄屏、侧边栏收起三种尺寸截图验证 |
| 志愿者没有邀请码注册 | 从登录页切换注册，输入邀请码完成注册 |

## 回归门禁

每轮回归必须记录：

- Git commit。
- 测试环境。
- 通过项。
- 失败项。
- 阻塞项。
- 是否允许部署。
