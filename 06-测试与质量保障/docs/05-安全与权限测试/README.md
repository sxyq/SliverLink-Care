# 安全与权限测试规划

## 测试目标

安全测试重点验证隐私保护、权限边界、签名校验和防串档。

## P0 安全用例

| 风险 | 测试点 |
| --- | --- |
| 扫码串档 | A 二维码验证 session 不能读取 B 老人健康信息 |
| 验证状态复用 | 浏览器切换二维码 token 后必须清空验证态 |
| 未验证访问 | 未验证不能访问健康档案、用药、量表 |
| 手机/身份证错误提示 | 错误字段必须对应，不泄露其他信息 |
| 后台权限 | 非授权角色不能进入受限菜单 |
| 短信中转签名 | 缺 header、签名错误、时间戳过期全部拒绝 |
| 审计日志 | 失败访问也要记录来源 IP 和操作对象 |
| 隐私脱敏 | 未验证状态只展示脱敏姓名/电话/档案号 |

## 当前脚本

```bash
node 06-测试与质量保障/scripts/security/api_negative_smoke.mjs
```

该脚本只执行缺 token、错 token、无签名等负例请求，不创建、不修改、不删除业务数据。更完整的安全测试需要在本地后端和 Testcontainers 测试库中覆盖 nonce 重放、timestamp 过期、跨角色、跨老人 session 拒绝等用例。
