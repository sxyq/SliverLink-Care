# 功能测试规划

## 测试目标

功能测试验证用户能否完成真实业务流程，重点看页面加载、表单输入、按钮点击、状态变化、错误提示和权限限制。

## 分端目录建议

- `扫码用户端.md`: 二维码访问、身份登记、短信验证、健康档案查看。
- `志愿者与家属端.md`: 登录、邀请码注册、老人管理、二维码查看。
- `管理后台端.md`: 管理员登录、表格页面、审核、权限、日志。
- `安卓短信端.md`: 权限、配置、短信解析、上传、心跳。

## 第一批功能用例

| 模块 | 用例 | 优先级 |
| --- | --- | --- |
| 扫码端 | 有效二维码进入基础信息页 | P0 |
| 扫码端 | 身份证错误提示身份证错误，不误报手机号 | P0 |
| 扫码端 | 验证成功后显示当前二维码绑定老人 | P0 |
| 扫码端 | 不同二维码之间验证状态不能串用 | P0 |
| 志愿者端 | 邀请码注册成功后自动登录 | P0 |
| 志愿者端 | 查看/复制/重新生成二维码 | P0 |
| 家属端 | 邀请码绑定老人 | P0 |
| 管理后台 | 老人档案表格操作按钮在各尺寸可见 | P0 |
| 管理后台 | 二维码弹窗复制链接和打开扫码页可用 | P0 |
| 管理后台 | 审计日志筛选和导出 | P1 |
| 安卓端 | 收到匹配短信后上传验证 | P0 |
