# 集成测试规划

## 测试目标

集成测试验证多个模块之间的数据契约是否一致，尤其是二维码、验证 session、短信中转、审计日志和权限之间的串联。

## 核心链路

1. 管理后台或后端生成二维码。
2. 扫码端用 token 调用 `resolve`。
3. 创建身份登记或短信验证 session。
4. 使用 session 访问受保护接口。
5. 后端校验 `sessionId + elderId + target` 一致。
6. 写入审计日志。
7. 管理后台审计页可查看该记录。

## 集成测试边界

- 不用真实短信时，使用后端直接身份登记或测试 fixture。
- 涉及数据库写入的测试必须使用测试库或可清理数据。
- 涉及服务器的测试必须显式标记环境，避免误写生产数据。
