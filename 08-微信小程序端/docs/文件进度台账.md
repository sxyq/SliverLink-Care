## 更新规则

| 规则 | 说明 |
| --- | --- |
| 只允许两种状态 | 只能写 `已做完` 或 `未做完` |
| 注释占位不算完成 | 只有真实实现并完成本批次自测后才能改为 `已做完` |
| 文件级更新 | 后续每次开发完成后，必须同步更新对应文件状态 |
