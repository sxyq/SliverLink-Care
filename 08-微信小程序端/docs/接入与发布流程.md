# 微信接入与发布流程

本文档描述如何把本目录的小程序工程导入微信开发者工具、绑定 `AppID`、上传代码并提交审核。

## 一、准备项

在开始前，你需要先准备好：

1. 微信公众平台中的小程序账号
2. 该小程序的 `AppID`
3. 已备案且可访问的正式业务域名
4. 可用于小程序请求的 `HTTPS` 接口地址
5. 小程序管理员或开发者权限

## 二、绑定 AppID

### 方式一：新建项目时绑定

1. 打开微信开发者工具
2. 使用管理员或开发者微信扫码登录
3. 点击 `小程序`
4. 选择 `导入项目` 或 `新建项目`
5. 项目目录选择本地 `08-微信小程序端`
6. 在 `AppID` 输入框填入微信公众平台对应小程序的 `AppID`
7. 项目名称填：`智联名牌`
8. 后端服务选择 `不使用云服务` 或按实际情况选择
9. 完成后工具会把该 `AppID` 与本地项目关联

### 方式二：通过配置文件绑定

在微信开发者工具识别的项目根目录放置 `project.config.json`，其中写入：

```json
{
  "appid": "你的小程序AppID",
  "projectname": "智联名牌",
  "miniprogramRoot": "dist",
  "compileType": "miniprogram"
}
```

本目录已提供示例文件：

- `project.config.json.example`

使用时复制为 `project.config.json`，再把 `appid` 替换成真实值。

## 三、导入微信开发者工具

推荐流程：

1. 先在本地执行构建，把可上传产物输出到 `dist`
2. 打开微信开发者工具
3. 选择 `导入项目`
4. 目录指向 `08-微信小程序端`
5. 工具读取 `project.config.json`
6. 完成后点击 `编译`
7. 在模拟器和真机预览中检查首页、扫码、登录、角色分流是否正常

## 四、服务器域名配置

在微信公众平台：

1. 进入对应小程序后台
2. 打开 `开发` -> `开发设置`
3. 配置服务器域名

至少要补：

- `request` 合法域名
- `downloadFile` 合法域名
- 如有 WebSocket，再补 `socket` 合法域名

注意：

- 只能使用 `https`
- 不能直接填 IP
- 域名必须已备案
- 小程序正式请求时必须通过证书校验

## 五、上传代码

完成联调后，在微信开发者工具中：

1. 点击 `上传`
2. 填写版本号
3. 填写项目备注
4. 确认上传

建议版本规范：

- `0.1.0`：首个提审版
- `0.1.1`：审核修订版
- `0.2.0`：新增统一工作台版

建议备注规范：

- `首版提审：首页+扫码查看`
- `补充：志愿者家属统一登录`
- `修复：扫码验证与导出`

## 六、提交审核与发布

代码上传成功后：

1. 登录微信公众平台
2. 进入对应小程序后台
3. 选择已上传版本
4. 填写版本说明、测试信息、审核说明
5. 提交审核
6. 审核通过后点击发布

## 七、审核说明建议

首版建议只提这两个入口：

1. 首页 `扫码查看`
2. 首页 `志愿者 / 家属登录`

审核说明建议写清：

- 扫码用于查看老人基础档案信息
- 志愿者与家属共用统一工作台
- 家属和志愿者靠账号角色区分权限
- 不提供医疗诊断，仅做信息展示和照护记录

## 八、正式提审前检查

1. `AppID` 是否绑定正确
2. 首页文案、头像、名称是否与备案一致
3. 域名是否全部为 `https`
4. 是否已配置隐私政策与用户隐私保护指引
5. 是否准备好审核测试账号
6. 是否准备好审核路径说明
7. 是否准备好异常页和空态页
