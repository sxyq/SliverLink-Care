# 开发批次计划

本计划基于 `docs/文件进度台账.md` 当前状态制定。

## 一、批次划分原则

- 先做能跑起来的底座
- 再做首页与扫码主链路
- 再做统一登录与工作台主链路
- 最后再补扩展页、导出、发布适配

## 二、批次总览

### 第 0 批

状态：`已做完`

目标：

- 建立目录结构
- 建立命名规范
- 建立索引文档
- 建立双码与双入口策略
- 建立页面与样式占位文件

交付文件范围：

- 所有 `docs/`
- 所有 `.gitkeep`
- 所有占位 `index.scss`
- 现有注释型规划文件

- 写通环境配置与请求基础层
