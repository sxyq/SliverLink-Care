# pages 目录开发说明

`pages` 存放扫码用户端页面级组件。

## 页面清单

| 文件 | 功能 |
| --- | --- |
| `BasicInfoPage.tsx` | 扫码后基础信息页 |
| `SmsVerifyPage.tsx` | 短信发送指引与验证状态页 |
| `HealthArchivePage.tsx` | 健康档案页 |
| `MedicationPage.tsx` | 主要用药页 |
| `ScaleSummaryPage.tsx` | 量表摘要页 |
| `NameplatePreviewPage.tsx` | 实体名牌预览与 PDF 下载页 |
| `NotFoundPage.tsx` | 二维码异常页 |

## 与安卓短信中转端的一致性要求

`SmsVerifyPage.tsx` 必须与 `D:\Project\SilverLink Care\ui_overview_images\android_sms_relay_google_style.png` 使用同一套状态表达：

- 等待中
- 已验证
- 上传失败 / 验证失败
- 待重试

页面不再以“输入验证码”作为主交互，而是以“发送指定短信并等待系统自动验证”为主交互。
