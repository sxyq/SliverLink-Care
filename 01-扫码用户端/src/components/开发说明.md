# components 目录开发说明

## 目录职责

`components` 存放扫码端通用 UI 组件，组件只负责展示和触发事件，不直接调用后端接口。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `InfoCard.tsx` | 展示姓名、年龄、血型、过敏史等基础信息 | 已完成 |
| `ActionButton.tsx` | 一键拨打、查看健康档案等主要操作按钮 | 已完成 |
| `VerificationBadge.tsx` | 展示“需短信验证”“已验证”等状态 | 已完成 |
| `SensitiveField.tsx` | 脱敏字段展示组件 | 已完成 |
| `MedicationList.tsx` | 主要用药列表 | 已完成 |
| `ScaleSummaryCard.tsx` | PHQ-9、GAD-7、UCLA 摘要 | 已完成 |

## 设计要求

- 移动端优先。
- 字体和按钮必须适合紧急场景快速识别。
- 不展示健康检测、诊断、预约等非需求能力。

## 概念图组件复刻细节

### `InfoCard.tsx`

- 使用白色背景、`1px` 浅绿色边框、`8px` 圆角、轻阴影。
- 字段名使用 `12px` 灰色文字，字段值使用深色加粗。
- 短字段两列布局，过敏史等长字段独占整行。

### `ActionButton.tsx`

- 普通主按钮使用蓝绿色背景 `#126B78`。
- 紧急拨号按钮使用橙色背景 `#D77B25`。
- 所有按钮高度不小于 `44px`，图标 + 文本水平居中。

### `VerificationBadge.tsx`

- “需验证”状态使用浅橙色或浅灰背景。
- “已通过短信验证”状态使用浅绿色背景和绿色文字。
- 图标优先使用 `LockKeyhole` 或 `ShieldCheck`。

### `SensitiveField.tsx`

- 手机号默认显示为 `138****5678` 形式。
- 组件不得提供“直接展开完整手机号”的普通按钮。
- 完整号码只允许用于拨号链接或后端授权后的场景。

### `MedicationList.tsx`

- 每条用药记录以一行轻分隔或小卡片展示。
- 不使用复杂表格边框，保证手机端阅读。

### `ScaleSummaryCard.tsx`

- 三个量表分数使用 chip 或小卡片展示。
- 必须在组件底部保留“非诊断”说明插槽。
