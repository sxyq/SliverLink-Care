# verification 功能开发说明

## 目录职责

`features/verification` 管理扫码端短信二次验证业务。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `verificationStore.ts` | 管理验证码倒计时、验证状态、错误次数、授权有效期 | 已完成 |
| `verificationService.ts` | 组合短信发送、短信校验、敏感查看授权流程 | 已完成 |

## 业务规则

- 未验证不能查看健康档案、主要用药、量表记录。
- 验证失败不展示敏感信息。
- 验证通过后授权应有短有效期。
- 验证行为必须写入操作日志。
