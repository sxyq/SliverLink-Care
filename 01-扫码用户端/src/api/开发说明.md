# api 目录开发说明

## 目录职责

`api` 存放扫码用户端对统一后端的请求封装。所有接口请求必须从这里发出，页面组件不得直接写 `fetch`。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `httpClient.ts` | 统一请求封装，读取 API Base URL，附带 JWT、requestId、接口签名字段 | 已完成 |
| `scanApi.ts` | 封装 `/api/scan/resolve`、`/api/scan/archive`、`/api/scan/medications`、`/api/scan/scales` | 已完成 |
| `smsApi.ts` | 封装 `/api/sms/send`、`/api/sms/verify` | 已完成 |
| `auditApi.ts` | 上报扫码、验证、查看敏感信息等操作日志 | 已完成 |

## 接口约束

- 二维码 token 只作为参数传给后端，不在前端解密。
- 敏感详情接口必须在短信验证通过后调用。
- 所有错误统一转换为页面可展示的错误信息。
