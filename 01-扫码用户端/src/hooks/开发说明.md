# hooks 目录开发说明

## 目录职责

`hooks` 存放扫码端复用状态逻辑。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `useQrToken.ts` | 从 URL path 或 query 中读取加密二维码 token | 已完成 |
| `useScanBasicInfo.ts` | 加载扫码基础信息，管理 loading/error 状态 | 已完成 |
| `useProtectedArchive.ts` | 验证后加载健康档案、用药、量表 | 已完成 |

## 注意事项

- hook 不负责二维码解密。
- hook 不直接展示 UI，只返回状态和操作函数。
