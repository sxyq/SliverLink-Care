# styles 目录开发说明

## 目录职责

`styles` 存放扫码端主题和移动端样式。

## 计划文件

| 文件 | 代码功能 | 状态 |
| --- | --- | --- |
| `theme.css` | 颜色、字号、间距、圆角等设计变量 | 已完成 |
| `mobile.css` | 手机端布局、按钮、卡片、表格适配 | 已完成 |

## 设计要求

- 页面适合微信内置浏览器访问。
- 按钮不应过小。
- 文本不能溢出卡片或按钮。

## 概念图样式复刻参数

| 样式项 | 规范 |
| --- | --- |
| 页面背景 | `#EDF7F4` 或 `#F4FAF8` |
| 主色 | `#126B78` |
| 安全状态色 | `#0A8067` |
| 紧急按钮色 | `#D77B25` |
| 主文本 | `#17212B` |
| 次文本 | `#667783` |
| 边框 | `#D8E7E3` |
| 内容最大宽度 | `480px` |
| 页面边距 | `16px` 到 `18px` |
| 卡片圆角 | 不超过 `8px` |
| 按钮高度 | 不小于 `44px` |

禁止使用紫色渐变、深色科技风、装饰光斑、大面积营销 hero。
