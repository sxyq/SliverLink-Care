# 扫码用户端 UI 复刻规范

## 1. 视觉基准

基准概念图：

```text
D:\Project\SilverLink Care\ui_overview_images\new_01_scan_user_overview.png
```

该图是一张横向概览图，包含 5 个手机界面：基础信息页、短信验证码页、健康档案详情页、主要用药页、量表记录摘要页。开发时不要求做成一张概览图，而是要把每个手机界面复刻成真实页面。

## 2. 整体风格

- 风格：医疗志愿服务类 H5，干净、可信、温和。
- 页面基调：白底卡片 + 浅绿色/浅蓝背景 + 医疗蓝绿色主色。
- 视觉关键词：救助、隐私保护、验证后查看、紧急联系。
- 不能做成营销落地页，不要大面积宣传文案，不要插画型 hero。

## 3. 颜色规范

| 用途 | 颜色建议 | 用法 |
| --- | --- | --- |
| 页面背景 | `#EDF7F4` / `#F4FAF8` | 移动端整体背景 |
| 主色 | `#126B78` | 顶部标题区、主按钮、已验证状态 |
| 辅助色 | `#0A8067` | 安全、通过、健康档案状态 |
| 强提醒色 | `#D77B25` | 一键拨打、紧急联系人按钮 |
| 文本主色 | `#17212B` | 标题、关键数据 |
| 文本次色 | `#667783` | 字段名、说明 |
| 边框色 | `#D8E7E3` | 卡片、输入框、分割线 |

禁止使用紫色渐变、深色科技风、过度装饰背景。

## 4. 布局规范

### 页面宽度

- 手机端最大内容宽度：`480px`。
- 页面左右边距：`16px` 到 `18px`。
- 卡片间距：`12px` 到 `16px`。
- 卡片圆角：不超过 `8px`。

### 顶部区域

基础信息页顶部必须有安全访问提示，例如：

```text
HTTPS 安全访问 · 微信扫码
智联名牌
扫码后先展示基础救助信息，敏感档案需短信验证。
```

右侧可使用 `ShieldCheck` 图标。

### 卡片布局

- 基础信息使用一张主卡片展示。
- 健康档案、用药、量表各自使用独立卡片。
- 不允许卡片套卡片。
- 每张卡片内部字段使用两列信息网格，长字段独占一整行。

## 5. 页面复刻细节

### 5.1 基础信息页

必须首屏展示：

- 健康档案编号。
- 姓名。
- 性别。
- 年龄。
- 紧急联系人姓名。
- 联系人与老人关系。
- 脱敏联系电话，例如 `138****5678`。
- ABO 血型。
- Rh 血型。
- 过敏史摘要。
- 一键拨打紧急联系人按钮。

按钮规范：

- “一键拨打紧急联系人”使用醒目的橙色按钮。
- 按钮高度不小于 `44px`。
- 按钮左侧使用电话图标。

### 5.2 短信验证码页

触发条件：

- 点击查看健康档案。
- 点击查看主要用药。
- 点击查看量表记录。

界面要求：

- 明确标题：“查看健康档案需二次验证”。
- 显示锁图标或盾牌图标。
- 验证码输入框高度不小于 `44px`。
- “发送验证码”“验证”按钮使用主色。
- 验证失败时只提示验证码错误，不暴露敏感信息。

### 5.3 健康档案详情页

顶部必须显示：

```text
已通过短信验证
```

展示字段：

- 填写日期。
- 负责志愿者。
- 身高。
- 体重。
- 腰围。
- BMI。
- 健康状态自评。
- 生活自理能力自评。
- 认知功能粗筛。
- 情感状态粗筛。

### 5.4 主要用药页

用药记录使用列表或轻表格，不使用密集大表格。

每条记录展示：

```text
药物名称 · 用量 · 用法 · 用药时间
```

### 5.5 量表记录摘要页

以摘要卡片展示：

- PHQ-9 分数。
- GAD-7 分数。
- UCLA 分数。
- 填写日期。
- 负责志愿者。

必须显示提示：

```text
量表记录为社区随访记录，不作为医疗诊断结论。
```

## 6. 组件样式

| 组件 | 样式要求 |
| --- | --- |
| 卡片 | 白底、1px 浅边框、8px 圆角、轻阴影 |
| 主按钮 | 主色背景、白字、图标 + 文本 |
| 紧急按钮 | 橙色背景、电话图标 |
| 安全徽标 | 浅绿色底、绿色文字、盾牌/锁图标 |
| 输入框 | 44px 高度、8px 圆角、浅边框 |
| 信息字段 | 字段名小号灰色，字段值加粗深色 |

## 7. 禁止出现

- 健康检测能力。
- 实时生命体征监测。
- 智能诊断。
- 预约挂号。
- 家庭聊天。
- 运动步数、心率、血压实时图表等硬件监测内容。

## 8. UI 验收标准

- 与概念图保持同一视觉方向：白底卡片、蓝绿色主色、橙色紧急按钮、隐私验证提示。
- 首屏能直接完成救助识别和拨打联系人。
- 未验证状态下不能出现完整健康档案、用药、量表详情。
- 手机宽度 `375px` 下文本不溢出、不重叠。
- 所有按钮高度不小于 `44px`。
- 所有敏感字段默认脱敏。
