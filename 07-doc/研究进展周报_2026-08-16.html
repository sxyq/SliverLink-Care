三语国际化与 RTL 适配收尾

SilverLink Care 面向老人与志愿者，服务地区需同时使用中文、维吾尔语与哈萨克语。本周为扫码 H5、志愿者填写端与微信小程序补齐三语支持，三端共用一份词条源，维、哈语言下布局与交互整体镜像。8 月 17 日完成小程序尺寸矩阵、志愿者端线上子路径修复和公网语言菜单复核；家属协管统一账号模型已确认，现有绑定迁移尚待指定账号。

本周范围 管理后台与安卓短信中转端保持中文，不在本轮。语言切换入口固定于物理右上角：中文 / ئۇيغۇرچە / قازاقشا。

共享词条与语言切换

词条集中至 shared/i18n，按 common、auth、scan 等分组，三端读取同一份，684 个键三语一一对应。语言选择存于 silverlink.locale，默认中文，异常值自动回退中文。菜单支持键盘操作，外部点击关闭后焦点回到触发按钮。

RTL 与小程序适配

维、哈语言下布局与按钮顺序镜像，图标仅镜像一次。手机号、剂量等数据强制 LTR，姓名与药品名按内容自动判定方向。小程序适配中，Taro 的 App 组件不进入页面树，语言菜单一度无法显示；改为每页包裹 I18nPageShell 后，15 个页面逐页接入解决。

错误文案本地化与四轮审查

扫码接口返回 500 时曾将英文技术异常直接展示给用户。三端 HTTP 客户端统一改为按当前语言显示通用失败提示，后端同步返回稳定错误键，13 个页面的错误状态随语言切换重译。审查由无上下文的独立代理执行四轮，误判当轮撤回，确认的问题当轮修复并提交。

发布验证与线上资源修复 2026-08-17

微信小程序开发版本 0.1.3 已上传，三种设备尺寸下的三语言页面矩阵完成。小程序上传 source map 已关闭，构建产物未发现 map 文件。志愿者端线上页面曾将 JS 和 CSS 指向根路径 /assets，Nginx 实际资源映射位于 /silverlink/volunteer/assets；在 Vite 增加子路径 base 后，构建、158 项测试和公网加载均通过。公网首屏已确认右上角“中文⌄”按钮、三项语言菜单和 RTL 切换可用。

家属协管账号模型确认 待实施

现有家属协管页面、接口和老人绑定功能仍可用，但当前实现使用独立家属认证。产品要求已明确为志愿者与家属协管共用账号和登录入口，通过入口标签区分功能范围。家属绑定记录需要先明确迁移到哪个统一账号；在该映射确认前，本轮不调整认证、权限或线上数据。
