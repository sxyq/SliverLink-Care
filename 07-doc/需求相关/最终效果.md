# 当前最终效果

## 版本信息

- 版本：`0.1.5`
- 适用范围：小程序名牌页面、工作台名牌预览、扫码端名牌预览、PDF 导出。
- 统一渲染：预览和导出 PDF 使用后端同一套名牌渲染结果。

## 一、三项版式需求

| 需求 | 修改前 | 修改后 |
| --- | --- | --- |
| 名称统一 | 名牌名称存在旧称或多处不一致 | 统一为“智联卡片” |
| 正面品牌排列 | 品牌主标题与副标题排列层级不清 | “智联卡片”与“智护空巢”横向排列，主标题更大，副标题更小 |
| 背面信息布局 | 参考图中橙色区域内容位置不符合目标版式 | 将内容移动到绿色标记区域；二维码在左，品牌区在右，品牌区位于扫码提示上方 |

## 三、显示与导出规则

- 小程序页面查看、PDF 预览和导出 PDF 的品牌名称必须保持一致。
- 品牌主标题使用较大字号，副标题使用较小字号，避免团队名称与卡片名称混淆。
- 背面二维码、品牌区、扫码提示、档案编号和底部文案保持固定层级。
- 下方横线避开图标；档案编号横线覆盖实际编号长度，不因数字变化出现明显空缺。
- PDF 不新增头像，不改变原卡片背景，也不写入健康档案、用药和量表内容。

## 四、验收记录

- 中文、维吾尔语、哈萨克语、彝语资源通过覆盖校验。
- 名牌服务测试覆盖品牌文字、正反面区域、档案编号、模板位置和缓存结果。
- 小程序预上传流程包含构建、单元测试、页面渲染、多语言审计、产物和性能校验。
